# Deployment Guide

## Phase 1: Infrastructure
- Setup PostgreSQL (Supabase/AWS RDS)
- Setup Redis (Upstash/AWS ElastiCache)
- Get RPC Keys (Alchemy/Infura)

## Phase 2: Smart Contracts
- Test on Sepolia/Goerli
- Deploy to Mainnet
- Verify on Etherscan

## Phase 3: Backend & Frontend
- Deploy Backend to Railway/Render
- Deploy Frontend to Vercel
- Set Environment Variables

## Estimated Costs
- ~$1,500/month at scale
